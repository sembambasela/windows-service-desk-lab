# Lab Planning

## Goal
Build a portfolio demonstrating entry-level Windows IT Service Desk capabilities: system inventory, local identity administration, access control, Windows services, network troubleshooting, and ticket documentation.

## Platform
Apple M1 MacBook (8 GB RAM), Oracle VirtualBox, Windows 11 ARM64. One Windows VM is used to avoid excessive host memory use.

## Lab sequence
1. Windows System Diagnostics — completed.
2. Local User Account Administration — planned.
3. File and NTFS Permissions — future.
4. Services and Event Viewer Troubleshooting — future.
5. Networking and Connectivity — future; initial incident already open.
6. Ticket and Service Request Documentation — ongoing.
